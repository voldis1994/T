TEHNISKĀ ATSAUCE / TIRDZNIECĪBAS ROBOTAM
Capital.com API
Datu katalogs • REST API un WebSocket
Iepriekšējās sarunas informācija par Capital.com publisko API: cenas un sveces, instrumenti, klientu sentiments,
likviditātes indikācijas, finansēšanas izmaksas, konts, pozīcijas, orderi un robota aprēķināmie rādītāji.
Šis dokuments apkopo iepriekš sniegtās 14 sadaļas, nevis neatkarīgi pārbaudītu pilnīgu API shēmu. API versija, pieejamie lauki un
jurisdikcijas ierobežojumi var mainīties. Pirms integrācijas pārbaudīt oficiālo dokumentāciju un DEMO atbildes.
Oficiālā dokumentācija: https://open-api.capital.com/

izmantojami; garantētajam Stop Loss ir arī hedging režīma ierobežojums.
